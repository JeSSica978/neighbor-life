## 6. 秒杀业务依赖的结构事实

- `tb_seckill_voucher.voucher_id` 是 unsigned bigint 主键，非自增；同券库存行唯一。`stock` 是有符号 int NOT NULL，数据库没有非负 CHECK，业务在更新条件中使用 `stock > 0`。
- `tb_voucher_order.id` 是有符号 bigint、IdType.INPUT、非自增，订单 ID 由 RedisIdWorker 生成。主键与 `uk_voucher_order_user_voucher(user_id,voucher_id)` 均存在，复合顺序相同。`pay_type/status` 为 NOT NULL 默认 1；时间字段 NULL/默认值逐项保留。
- `createVoucherOrder` 在事务中检查订单主键、锁定秒杀券行并条件扣库存；本轮只审查结构支持，不重复发送消息或下单验证。见 [VoucherOrderServiceImpl.createVoucherOrder](<D:/Development/neighbor-life/src/main/java/com/hmdp/service/impl/VoucherOrderServiceImpl.java:121>)、[库存锁定 Mapper](<D:/Development/neighbor-life/src/main/java/com/hmdp/mapper/SeckillVoucherMapper.java:17>)、[VoucherOrder 实体](<D:/Development/neighbor-life/src/main/java/com/hmdp/entity/VoucherOrder.java:32>)。
- Outbox 实际是 Redis Stream：Lua XADD 与预扣在同一脚本，发布器读 Stream，Kafka 确认后删条目。开发库没有 Outbox 表，loadtest 模板也没有；不需要臆造数据库 Outbox 表。见 [seckill.lua](<D:/Development/neighbor-life/src/main/resources/seckill.lua:46>) 与 [SeckillOrderPublisher](<D:/Development/neighbor-life/src/main/java/com/hmdp/messaging/SeckillOrderPublisher.java:32>)。
