## 普通运行与 F5 的区别

- F5 使用 `.vscode/launch.json` 的 `NeighborLife: Java Debug (JDK 11)` 配置，启动带 JDWP 的 Java 进程；命中断点才会暂停，未暂停时系统仍可正常使用。
- Shift+F5 停止当前调试进程。停止后按 Ctrl+Shift+B，运行默认任务 `NeighborLife: Run Backend (Maven)`，即可普通运行。
- 也可以通过 Ctrl+Shift+P → `Tasks: Run Task` → `NeighborLife: Run Backend (Maven)` 启动。这个任务在 Tasks 中，不在 Run and Debug 的调试配置下拉列表中。
- 普通运行时没有断点暂停；同一套前后端都由 8081 上的 Spring Boot 提供，无需单独启动前端。

在项目终端可直接执行：

```powershell
.\tools\Invoke-NeighborLife.ps1 -Action Run
```

Run 脚本先检查 8081、启动或检查 MySQL/Redis/Kafka，再运行 Maven。不要在现有 F5 进程仍占用 8081 时重复启动。普通运行在该终端按 Ctrl+C 停止。

## 日志开关

修改位置是 `src/main/resources/application.yaml` 的 `logging.level`：

| 日志 | 当前设置 | 效果 |
| --- | --- | --- |
| 应用业务 | `com.hmdp: info` | 保留业务 INFO/WARN/ERROR，包括秒杀 Lua、发送、消费和落库标志 |
| SQL 及参数 | `com.hmdp.mapper: debug` | 打印 Preparing、Parameters、Total |
| 本地验证码 | `com.hmdp.service.impl.UserServiceImpl: debug` | 保留验证码；本项目没有实际短信平台 |
| Kafka 客户端 | `org.apache.kafka: warn` | 隐藏大段 Consumer/Producer/Admin 配置和入组细节，保留 WARN/ERROR |
| Redisson | `org.redisson: warn` | 隐藏连接池初始化细节，保留 WARN/ERROR |
| Repository 扫描 | `org.springframework.data.repository.config: warn` | 隐藏仓库扫描提示 |

Spring Kafka 容器的分区分配 INFO 日志仍保留，方便确认监听已启动。`SECKILL_CONSUMED ... transactionCommitted=true` 与 MySQL 查询结果用于确认订单提交；不要只凭客户端入组或事务内 INSERT 日志判定成功。

Spring Boot 图案使用 `spring.main.banner-mode: "console"` 开启；MyBatis-Plus 图案使用 `mybatis-plus.global-config.banner: true` 开启。日期格式为 `HH:mm:ss.SSS`，显示时、分、秒。

YAML 日志设置需要重新启动应用才会生效。Java/CGLIB 的 `illegal reflective access` 警告直接来自 JVM，不受 `logging.level` 控制；这里没有压制该兼容警告。普通 Run 脚本的健康检查标志和 Maven BUILD SUCCESS 也保留。
